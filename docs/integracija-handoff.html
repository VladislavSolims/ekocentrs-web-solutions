Anketas integrācija ekocentrs.lv vietnē

AML/KYC klienta identifikācijas anketa ir patstāvīga Next.js lietotne. Tā netiek instalēta Joomla iekšienē — tā darbojas uz sava subdomain, un no vietnes uz to ved saite. Šis dokuments apraksta visu, kas jādara Joomla pusē.

Vietne
Joomla 3.10.10
Lietotne
Next.js 16 / Node
Subdomain
anketa.ekocentrs.lv
Joomla koda izmaiņas
1 fails

Īsumā

  1. Anketa tiek izvietota uz anketa.ekocentrs.lv (Vercel vai jūsu serveris).
  2. Joomla saknē tiek pievienots viens PHP fails — autorizācijas tilts.
  3. Joomla izvēlnē parādās saite uz šo failu; tā ir redzama tikai aģentu lietotāju grupai.
  4. Klientam nekas nav jāreģistrē — viņš aizpilda anketu pa saiti, ko atsūta aģents.

Darbības principa shēma

Joomla paliek vienīgā vieta, kur glabājas aģentu paroles. Anketas lietotne pati paroles nepārbauda un nesaglabā — tā uzticas īsdzīvojošam, parakstītam marķierim, ko izsniedz Joomla. 

Aģents → anketa.ekocentrs.lv/izveidot
             │  nav sesijas
             ▼
        ekocentrs.lv/kyc-sso.php
             │  Joomla pārbauda: vai pieteicies? vai pareizajā grupā?
             │  ja nav pieteicies → parastā Joomla login forma
             ▼
        pāradresācija atpakaļ ar marķieri (derīgs 30 s, parakstīts ar HMAC)
             ▼
     anketa.ekocentrs.lv/api/auth/joomla
             │  pārbauda parakstu → uzliek httpOnly sesijas sīkdatni
             ▼
          /izveidot  — aģents izveido saiti klientam

Klients → /aizpildit?d=…   (publiska lapa, autorizācija nav vajadzīga)

Ieviešanas soļi

Lietotnes izvietošana

Divas iespējas — izvēlieties to, kas jums ērtāka; abas mums der.

A. Vercel (bezmaksas, ātrākais)

Lietotni izvietojam mēs, jums paliek tikai DNS ieraksts no 2. soļa.

B. Jūsu serveris

Nepieciešams Node.js 20+ un reverse proxy. Lietotne klausās uz porta 3000:

npm ci
npm run build
npm start          # ports 3000

Piemēra nginx bloks:

server {
    server_name anketa.ekocentrs.lv;
    location / {
        proxy_pass         http://127.0.0.1:3000;
        proxy_set_header   Host $host;
        proxy_set_header   X-Forwarded-Proto $scheme;
    }
}

Svarīgi: PDF ģenerēšanai lietotne palaiž headless Chromium. Uz sava servera tam vajadzīgas sistēmas bibliotēkas (libnss3, libatk-bridge2.0-0, libdrm2, libgbm1, libasound2) un ~1 GB brīvas RAM. Uz Vercel tas darbojas bez papildu darbībām — tāpēc iesakām variantu A.

DNS ieraksts

Pievienojiet subdomain anketa.ekocentrs.lv:

# Variants A — Vercel
anketa   CNAME   cname.vercel-dns.com.

# Variants B — jūsu serveris
anketa   A       <servera IP>

TLS sertifikāts obligāts — bez HTTPS sesijas sīkdatne nestrādās.

Autorizācijas tilts Joomla pusē

Izveidojiet failu kyc-sso.php Joomla saknes direktorijā (blakus index.php). Tas ir vienīgais jaunais kods vietnē — Joomla kodols un paplašinājumi netiek aiztikti. 

<?php
/**
 * kyc-sso.php — tilts starp Joomla sesiju un anketas lietotni.
 * Ievieto Joomla saknes direktorijā.
 */
define('_JEXEC', 1);
define('JPATH_BASE', __DIR__);

require_once JPATH_BASE . '/includes/defines.php';
require_once JPATH_BASE . '/includes/framework.php';

// --- konfigurācija -------------------------------------------------
$secret  = '<KOPLIETOTAIS_NOSLĒPUMS>';   // sk. 5. soli
$appUrl  = 'https://anketa.ekocentrs.lv';
$groupId = 10;                            // aģentu lietotāju grupas ID
// -------------------------------------------------------------------

$app = JFactory::getApplication('site');
$app->initialise();

$user = JFactory::getUser();

// Nav pieteicies → parastā Joomla login forma, pēc tam atpakaļ šurp.
if ($user->guest) {
    $return = base64_encode(JUri::getInstance()->toString());
    $app->redirect(
        JRoute::_('index.php?option=com_users&view=login&return=' . $return, false)
    );
}

// Pieteicies, bet nav aģentu grupā → atpakaļ uz sākumlapu.
if (!in_array($groupId, $user->getAuthorisedGroups())) {
    $app->enqueueMessage('Jums nav piekļuves anketas rīkam.', 'error');
    $app->redirect(JRoute::_('index.php', false));
}

// Viss kārtībā → izsniedz marķieri, derīgu 30 sekundes.
$payload = json_encode([
    'sub'   => (int) $user->id,
    'name'  => $user->name,
    'email' => $user->email,
    'iat'   => time(),
    'exp'   => time() + 30,
    'jti'   => bin2hex(random_bytes(16)),
], JSON_UNESCAPED_UNICODE);

$body  = rtrim(strtr(base64_encode($payload), '+/', '-_'), '=');
$sig   = hash_hmac('sha256', $body, $secret);

$app->redirect($appUrl . '/api/auth/joomla?token=' . urlencode($body . '.' . $sig));

Marķieris ir base64url(JSON) + "." + HMAC-SHA256. Mūsu pusē paraksts tiek salīdzināts nemainīgā laikā, un derīguma termiņu mēs piemērojam paši — ne ilgāk par 30 sekundēm no iat, neatkarīgi no tā, ko prasa exp. Lietotne apzināti darbojas bez datubāzes, tāpēc izlietotie marķieri netiek glabāti; aizsardzība ir īsais logs un HTTPS.

Nepieciešams PHP 7.0+ — random_bytes() dēļ. Joomla 3.10 to prasa jebkurā gadījumā. Ja uz servera ir vecāks PHP, dodiet ziņu — nomainīsim uz citu nejaušības avotu.

Izvēlnes elements

Joomla admin → Izvēlne → Jauns elements → tips Ārēja URL: 

URL:              https://ekocentrs.lv/kyc-sso.php
Piekļuves līmenis: Special (vai jūsu aģentu līmenis)

Saite ved uz tiltu, nevis tieši uz anketu — tā aģents vienmēr iziet caur Joomla pārbaudi. Piekļuves līmenis tikai paslēpj saiti no citiem; īsto pārbaudi veic kyc-sso.php.

Bez iframe. Aģenta lapa nedrīkst tikt iebūvēta rakstā kā <iframe>: sesijas sīkdatne citā domēnā tiek uzskatīta par trešās puses sīkdatni, un daļa pārlūku to bloķē. Klienta anketu (/aizpildit) iframe-ā ielikt drīkst — tai autorizācija nav vajadzīga.

Koplietotais noslēpums

Ģenerējiet uz servera 32 baitu nejaušu virkni:

openssl rand -hex 32

To pašu vērtību ieraksta kyc-sso.php un nodod mums — mēs to ieliekam lietotnes vidē kā JOOMLA_SSO_SECRET. Lūdzam nodot to caur paroļu pārvaldnieku vai citu drošu kanālu, nevis e-pastā vai čatā. Ja noslēpums kādreiz nonāk nepareizās rokās — ģenerējiet jaunu, nomainiet abās vietās, un vecie marķieri uzreiz pārstāj darboties.

Pārbaude

  • Nepieteicies lietotājs atver izvēlnes saiti → redz Joomla login formu, pēc pieteikšanās nonāk anketā.
  • Pieteicies lietotājs ārpus aģentu grupas → tiek aizvests atpakaļ ar kļūdas paziņojumu.
  • Aģents atver anketa.ekocentrs.lv/izveidot tieši, bez sesijas → tiek pāradresēts uz Joomla.
  • Marķiera saite, atvērta vēlāk par 30 sekundēm → aģents tiek klusi aizvests atpakaļ uz Joomla pieteikties no jauna, nevis redz kļūdas lapu.
  • Klienta saite /aizpildit?d=… atveras anonīmi, arī citā pārlūkā un telefonā.

Ko mums vajag no jums

  • Kurš variants — Vercel (A) vai jūsu serveris (B)?
  • Aģentu Joomla lietotāju grupas nosaukums un ID.
  • Koplietotais noslēpums (5. solis), nodots drošā kanālā.
  • PHP versija uz servera.
  • Apstiprinājums, ka subdomain anketa.ekocentrs.lv ir izveidots.

Piezīme par Joomla 3.10

Joomla 3.10 atbalsts beidzās 2023. gada augustā — vietne vairs nesaņem drošības atjauninājumus. Uz anketu tas neattiecas: tā ir atsevišķa lietotne uz sava subdomain ar savu koda bāzi. Taču tilts no 3. soļa ir rakstīts Joomla 3 API (JFactory, JRoute), un pēc migrācijas uz Joomla 4/5 tas būs jāpārraksta uz Joomla\CMS\Factory. Ja migrācija ir plānota tuvākajā laikā, ir vērts vispirms migrēt un tikai tad likt tiltu — tā šo darbu nevajadzēs darīt divreiz.
